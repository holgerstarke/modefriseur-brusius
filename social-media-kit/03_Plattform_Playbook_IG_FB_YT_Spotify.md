# Plattform-Playbook (IG / FB / YT / Spotify)

## Instagram (Hauptfokus)
- Format: Reels-first (9:16, 15–35 Sek.)
- Hook: erste 1–2 Sekunden entscheiden
- Frequenz: 4–6 Reels/Woche + tägliche Stories
- CTA: Save, Share, Kommentar mit Meinung/Erlebnis

## Facebook
- Reels spiegeln + längere Caption mit persönlichem Kontext
- 3–4 Posts/Woche (Reel + Bild + Textpost-Mix)
- Community-Fragen funktionieren stark
- Fokus: Beziehung + Bestandsfans reaktivieren

## YouTube
- Shorts: 3–5/Woche (Hook-Zeilen, Studio, BTS)
- Longform: 1x Song-Visualizer/Video + 1x BTS/Monat
- Titel klar + Suchbegriffe (Songname, Offiziell Bajazzo, Deutschrap)

## Spotify
- Ziel: Social-Traffic auf Release
- Pre-Save vor Release aktiv pushen
- Release-Woche: tägliche Erinnerungen in Stories + CTA
- Nach Release: Snippets + Community-Reaktionen posten

## KPI-Rahmen (Startphase)
- Reel-Hook-Rate (3s Hold)
- Durchschnittliche Wiedergabedauer
- Saves + Shares pro Post
- Kommentare pro 1.000 Views
- Klicks auf Profil/Link in Bio
