# Social Media Agent Hub (MVP)

Interaktive Web-App (ohne Backend) für:

- Content-, Reichweiten-, Community- und Profil-Analysen
- kontinuierliches Wissens-Update (lokal via `localStorage`)
- Upload von `.md`, `.txt`, `.json`, `.csv`
- Download von Analyse-Reports (`.md`) und Wissensdatenbank (`.json` / `.md`)

## Start

1. Öffne `/home/runner/work/modefriseur-brusius/modefriseur-brusius/social-media-agents/index.html` im Browser.
2. Text oder KPI-Daten einfügen oder Dateien hochladen.
3. Agent auswählen und Analyse starten.
4. Insights manuell oder per Auto-Learning ins Wissen übernehmen.

## Hinweis

Die App analysiert eingegebene oder hochgeladene Inhalte lokal im Browser. Es werden keine externen APIs benötigt.
